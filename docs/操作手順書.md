# 操作手順書
## 日常
1. `python3 scripts/run_tests.py` を実行し全件合格を確認(スキル/設定/スクリプト/モデル変更の都度)。
2. レビュー時は skills/jp-contract-review-extension.SKILL.md の手順に従う。
## Word検証コマンド
- 適用: `apply_revisions.py 原本.docx revisions.json 出力.docx`
- 構造: `validate_docx.py 出力.docx --expect-ins N --expect-del N --expect-comments N`
- 差分: `compare_documents.py 原本.docx 出力.docx --revisions revisions.json`
## 利用者による手動試験(自動化不可・未実施)
- P-1 新規Coworkセッションを開き「実務プロファイルの先頭5行を読み上げて」→ 内容が一致すること
- P-2 Cowork再起動後にP-1を再実施
- P-3 `/commercial-legal:review` 実行時、冒頭に設定読込結果が表示されること
- P-4 `/commercial-legal:customize` で1項目変更 → 新規セッションで反映されること
- W-1 出力docxをMicrosoft Wordで開き、修復警告なし/変更履歴の承認・却下/コメント表示を確認
## プラグイン更新時
更新後に run_tests.py を再実行。プラグイン標準(CLAUDE.md雛形・SKILL.md)は更新で置換されるため、独自設定は config/ とWindows側永続フォルダにのみ置く。

## 追加(法的判断の検証)
- 全試験: `python3 -I scripts/run_tests.py`(既存46件) と `python3 -I scripts/run_legal_live_tests.py`(法的判断ゲート33件)。結果は logs/ と tests/legal_live/results/。
- 法令の取得: PCで `python3 -I scripts/fetch_egov.py 331AC0000000120 act_331AC0000000120 --alias 取適法 --former 下請代金支払遅延等防止法` を実行(外部通信が必要)。成功すると raw 応答とSHA-256が保存され、転記なしで取り込まれる。失敗時は終了コード2でキャッシュは変わらない。
- プラグイン導入: チャット内の jp-contract-verification.plugin カードの承認ボタンを押す(利用者の承認が必要)。導入後は新規セッションで「日本法で契約レビュー」と依頼して手順1(設定確認)から実行されることを確認。
- PC側ファイルの引渡し: 新しい空フォルダを作り、実務プロファイル(CLAUDE.md)をコピーして、そのフォルダだけを Add folder する。

## 追補(v3)
### 永続化の手動確認(自動試験不可)
- P-1: PCの新規空フォルダ(例 `C:\Users\<user>\Documents\CL-Extension-Work`)をClaudeデスクトップの「フォルダを追加」で接続し、実務プロファイル(CLAUDE.md)をそのフォルダへ保存する(既存があればコピー。**既存を優先し、上書き前に必ず控えを取る**)。
- P-2: 新しいチャットを開き、同フォルダを接続して `check_config.py <CLAUDE.md>` が PASS するか確認。
- P-3: プラグイン更新(再インストール)後も P-2 が PASS し、同フォルダの設定が残っているか確認。
- P-4: `/commercial-legal:review` を実行し、手順1で設定が読み込まれ停止しないことを確認。結果を報告すること(未確認のまま完了としない)。
