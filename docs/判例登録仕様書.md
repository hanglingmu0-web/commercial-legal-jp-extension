# 判例登録仕様書
必須: case_id, version, court, decision_date, case_number(分かる範囲), existence_status(unconfirmed/confirmed), fulltext_status(available/unavailable), original_verification(unverified/verified), structure_verification。
- `existence_status` が `confirmed` でない判例は、`original_verification: verified` にできない。確認根拠(official_url 等)が必要。
- 判決全文がない判例は `fulltext_status: unavailable` で登録可。「全文未確認」として扱い、確定的引用不可。
- 判決の「裁判所の判断(holdings: kind=court_holding)」と「当事者の主張(party_arguments)」「事実(key_facts)」は別配列。混同不可。
- 全文原本のSHA-256を登録時と読出時に照合。不一致は integrity_error。
- 引用の確定条件(`firm_citation`): 存在確認済み + 全文確認 + ハッシュ一致 + 引用文一致。ただし**法律上の関連性・射程は機械では判定せず「未評価」**。
